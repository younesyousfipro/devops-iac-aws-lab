# Decisions

DevOps decisions for this repository, recorded when they are made. The starting point is the OpenClassrooms starter kit (first commit), adapted to production-like practices.

## Hosting and repository (2026-11-09)

| Decision | Rejected | Reason |
|---|---|---|
| AWS for the three exercises | local Docker option; Azure | the starter kit covers AWS for all three exercises (managed OpenSearch for Ex2); the Ex1 Docker option boots a QEMU VM that needs `/dev/kvm`, not available on macOS; Azure only appears in the Ex3 title, with no starter files and no managed OpenSearch equivalent. Consequence: real costs, covered by the AWS Free plan credits; every session ends with `terraform destroy` |
| One repository, one folder per exercise (`01-provision-configure`, `02-observability-elk`, `03-load-balancing`) | one repository per exercise | the brief asks for one repository; the exercises are small; each folder has its own Terraform state, so nothing is shared |
| Hosted on GitHub as `devops-iac-aws-lab` | GitLab (named in the brief) | GitHub is the author's main platform; the Ex1 deliverable asks for a GitHub link; the deliverables are also uploaded as a zip |
| Starter kit history kept (initial commit), `origin` changed | fresh `git init` | the diff between the starter kit and this work stays visible, and the kit stays credited |
| Repository docs in English | French | readable by anyone reviewing the repository |

## Terraform foundations (2026-11-09)

| Decision | Rejected | Reason |
|---|---|---|
| Remote state in S3, native locking (`use_lockfile = true`) | local state; DynamoDB locking | the state survives the laptop and is locked during an apply; native S3 locking (Terraform 1.10+) replaces DynamoDB, now deprecated |
| State bucket created by a separate `00-bootstrap/` folder, with local state | bucket created by hand in the console | the bucket is code too; its own state holds nothing sensitive. Consequence: the bucket is not destroyed at the end of a session (cost: a few cents at most) |
| Existing public key registered with `aws_key_pair` (dedicated `id_ed25519_aws`) | key generated by Terraform (`tls_private_key`, starter kit) | a generated private key is stored in clear in the state; with an existing key, the private key never leaves the laptop |
| Production-like hygiene: SSH open to the author's IP only, pinned recent provider versions, AMI looked up by a data source | starter kit defaults (`0.0.0.0/0`, provider `~> 4.16`, hard-coded AMI) | least privilege; reproducible versions; an AMI ID gets outdated and differs by region |
| Default VPC | custom VPC with private subnets | private subnets need a NAT gateway, which is billed per hour; high availability is out of scope for these exercises |
